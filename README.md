Hangout — Party Game App

Aplicativo mobile desenvolvido com React Native + Expo focado em jogos rápidos e interativos para jogar com amigos.

O projeto reúne diferentes modos de jogo em uma experiência simples, dinâmica e divertida, com foco em interação social, partidas locais e interface moderna.

Sobre o projeto

O Hangout nasceu como um projeto de estudo e prática em desenvolvimento mobile, explorando conceitos como:

componentização;
gerenciamento de estados;
navegação entre telas;
organização de projeto;
lógica de jogos;
experiência do usuário em dispositivos móveis.

Além do aprendizado técnico, o objetivo também foi criar uma aplicação com identidade visual própria e experiência leve para grupos de amigos.

Modos de jogo

Atualmente o aplicativo possui alguns modos já funcionais:

Impostor

Um jogador recebe um papel diferente dos demais e precisa se misturar sem ser descoberto.

Contato

Modo baseado em associação e comunicação rápida entre jogadores.

Frase Cortada

Os participantes precisam completar ou interpretar frases parcialmente escondidas.

Adivinhe a Nota

Os jogadores tentam acertar avaliações/notas com base em temas apresentados.

Instalação

Clone o repositório:

git clone https://github.com/SouuSamuel/party-game-ui.git

Entre na pasta do projeto:

cd party-game-ui

Instale as dependências:

npm install

Inicie o projeto:

npx expo start
