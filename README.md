# Hangout

Protótipo visual mobile offline em React Native + Expo Router.

## Rodar

```bash
npm install
npx expo start -c
```

Abra no Expo Go compatível com Expo SDK 54.

## O que existe

- Home Screen
- Seleção de 4 modos
- Tela de preparação com regras
- Input de jogadores
- Lista visual com remover
- Botão Próximo apenas visual

## O que NÃO existe ainda

- Pontuação real
- Banco de palavras
- Temporizador
- Multiplayer online
- Algoritmos dos modos
